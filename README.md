# ESP32 Line-Follower Robot with PID Control 🤖

Автономный робот-линейщик на базе ESP32. Использует **ПИД-регулятор** для плавного и точного движения по линии, а также умеет распознавать перекрёстки.

## 🚀 Особенности
- **ПИД-регулятор** (Kp, Ki, Kd) с защитой от интегрального насыщения (anti-windup).
- **Нормализация датчиков**: сырые значения (0-4095) переводятся в понятную шкалу (0-1000), что делает код независимым от освещения.
- **Обнаружение перекрёстков** с защитой от дребезга (дебаунс 800 мс).
- **Автономный запуск**: робот стартует через 3 секунды после включения питания, компьютер не нужен.
- **Отладочный вывод** в Serial Monitor (текущая ошибка, значения P, I, D и скорость моторов).

## 🛠 Аппаратное обеспечение
- **Микроконтроллер:** ESP32 (38 pin)
- **Датчики линии:** 2 × TCRT5000 (GPIO 34 и GPIO 36)
- **Драйвер моторов:** L298N / TB6612
- **Пины моторов:**
  - Левый мотор: Вперёд (GPIO 21), Назад (GPIO 19)
  - Правый мотор: Вперёд (GPIO 23), Назад (GPIO 22)

## 📂 Как это работает
1. **Калибровка:** Перед запуском основной программы необходимо запустить `calibration_test.ino` и вписать полученные значения (min/max для белого и чёрного) в РАЗДЕЛ 2 основного кода.
2. **Чтение датчиков:** Значения нормализуются от 0 (белый фон) до 1000 (чёрная линия).
3. **Вычисление ошибки:** `error = normL - normR`. Если робот едет ровно, ошибка близка к нулю.
4. **ПИД-регулятор:** Вычисляет поправку `correction`. Левое колесо получает `BASE_SPEED - correction`, правое `BASE_SPEED + correction`.
5. **Перекрёсток:** Если оба датчика одновременно видят чёрную линию (> 800), выполняется манёвр (по умолчанию — ехать прямо).

## ⚙️ Настройка (Тюнинг ПИД)
В коде заданы стартовые коэффициенты:
- `Kp = 0.35`
- `Ki = 0.001`
- `Kd = 1.2`
- `BASE_SPEED = 140`

*Если робот виляет — уменьшите Kp. Если не успевает поворачивать — увеличьте Kp. Если «заносит» — немного увеличьте Kd.*
